# LightInk 轻墨 v1.0.1

最近打开记录管理能力更新。

## 新增

- **最近打开 · 全部清除**：欢迎页「最近打开」标签右侧新增「全部清除」按钮，一键清空全部记录
- **最近打开 · 单项移除**：鼠标悬停任意一条记录，右侧出现 ✕ 按钮，可单独移除该条记录
- 删除后列表即时刷新；清空后显示空态，清除按钮自动隐藏
- 最近列表路径规范化（resolve），删除与去重判定跨路径写法（正/反斜杠）一致

## 下载

| 文件 | 说明 |
|---|---|
| `LightInk-Setup-1.0.1.exe` | Windows 安装包（推荐）——双击安装，自动注册 `.md` 文件关联 |
| `LightInk-1.0.1-portable.zip` | 免安装便携版——解压即用 |

系统要求：Windows 10 / 11（64 位）。

> 安装包未做数字签名，SmartScreen 提示时选「更多信息 → 仍要运行」。

## 已知限制

- 安装包未签名
- 暂不支持多标签页与自定义 CSS（规划中）
