# LightInk 轻墨 v1.0.3

冷启动打开体验修复 + 命令面板优化。

## 修复

- **冷启动双击 .md / .txt 文件，现在能正确打开并直接进入阅读模式**
  - 根因：渲染层编辑内核为异步加载，冷启动时「打开文件」消息在监听注册前送达而丢失
  - 修复：主进程重试推送直至渲染层确认（ack 机制）+ 渲染层提前注册监听 + 初始化期间消息排队
  - 实测：`LightInk.exe 文件路径` 冷启动 → 文档打开、阅读模式、内容正确

## 优化

- **命令面板**：「模式：所见即所得」更名为「模式：编辑」，并重排为 阅读 → 编辑 → 源码（与工具栏一致）
