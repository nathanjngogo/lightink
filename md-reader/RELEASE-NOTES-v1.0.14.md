# LightInk 轻墨 v1.0.14

修复更新。

## 修复

- **新建文档弹窗的「保存地址」行真正隐藏**
  - v1.0.13 修复不彻底：真正的根因是 CSS 样式（`.dlg-dir{display:flex}`）覆盖了 HTML `hidden` 属性的隐藏效果，导致地址行**从始至终都在视觉上显示**——之前只改了属性没有改到渲染
  - 本次修复：全局 `[hidden]{display:none!important}` 规则，`hidden` 属性从此真正生效
  - 验证方式升级为**渲染层实测**（计算样式 + 实际占位高度），不再只看属性值

## 行为确认

| 场景 | 保存地址行 |
|---|---|
| 新建文档弹窗 | ❌ 不显示（只有文件命名） |
| 关闭未保存文档弹窗 | ✅ 显示完整路径，可编辑 + 📁 选择 |
