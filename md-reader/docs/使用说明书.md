# LightInk 轻墨 使用说明书

**本地 Markdown 编辑器 + 阅读器** · 所见即所得 · 自动保存 · 离线可用，数据不出本机。

- 适用版本：v1.0.14
- 适用系统：Windows 10 / 11（64 位）
- 支持格式：`.md` / `.markdown` / `.txt`

## 1. 安装与启动

1. 双击 `LightInk-Setup-1.0.14.exe` 启动安装向导。
2. 按需修改安装目录（默认装到当前用户目录，无需管理员权限）。
3. 完成安装。桌面与开始菜单会创建「**LightInk 轻墨**」快捷方式，同时注册 `.md` / `.markdown` / `.txt` 文件关联。
4. 双击任意 Markdown 文件，或从快捷方式启动。

> **首次运行提示「Windows 已保护你的电脑」？**
> 安装包当前未做数字签名，SmartScreen 可能出现提示。点击「更多信息」→「仍要运行」即可。本应用不联网、不收集任何数据。

## 2. 认识界面

| 区域 | 说明 |
|---|---|
| **标题栏** | 左侧为应用标识；中间为文件名与未保存圆点；右侧为最小化 / 最大化 / 关闭。空白处可拖动窗口。 |
| **工具栏** | 左组：侧栏开关、「新建」、模式切换（阅读 / 编辑 / 源码）；**中部：「搜索命令… Ctrl K」命令面板入口（胶囊样式居中）**；右组：「关闭文档」（仅打开文档时出现）、主题切换、导出、设置。 |
| **侧栏** | 两个页签：**大纲**——当前文档的标题目录，点击跳转；**书架**——自定义分类文件夹与文档列表。 |
| **编辑区** | 居中排版。新建文档时呈现 **A4 纸面**；打开已有文件为常规版心。 |
| **状态栏** | 当前模式、字数统计、渲染引擎、保存状态。 |

主题：「主题：自动」按钮点击一次循环切换 **自动 → 浅色 → 深色 → 自动**。「自动」跟随 Windows 系统深浅色。深色主题下整个编辑区（含新建文档的 A4 纸面）统一为深色。

## 3. 打开文档

四种入口：

- **双击文件（推荐）**：安装后 `.md` / `.markdown` / `.txt` 已关联 LightInk，在资源管理器双击即可。无论软件处于哪种状态，双击后都会**直接进入阅读模式**：
  - 软件**未运行**时双击 → 自动启动并打开文件，进入阅读模式；
  - 软件**已运行**时双击 → 在**同一窗口**打开（不会开出多个实例），进入阅读模式；
  - 软件**最小化到托盘**时双击 → 自动从托盘唤回界面，进入阅读模式。
- **欢迎页 · 最近打开**：启动时列出最近打开的文件（最多 12 条），点击即开。
- **拖拽**：把文件从资源管理器拖进窗口任意位置。
- **工具栏 / 命令面板**：`Ctrl K` 打开命令面板，搜索并执行「打开文件」。

需要修改内容时，切到「编辑」模式即可。

## 4. 编辑与三种模式

工具栏左组可随时切换，内容在三种模式间无缝流转。

| 模式 | 用途 |
|---|---|
| **阅读**（默认） | 打开文档即进入只读排版视图，隐藏全部编辑控件，适合通读与审阅。 |
| **编辑** | 所见即所得：直接在渲染后的页面上打字，Markdown 语法实时变成版式。支持撤销 / 重做（`Ctrl Z` / `Ctrl Y`）。 |
| **源码** | 纯文本 Markdown 源码，适合精确修改语法、批量替换。 |

### 自动保存

默认开启：停止输入约 **0.9 秒**后自动写回原文件，状态栏显示「已保存到文件 + 时间」。也可随时 `Ctrl S` 立即保存。可在设置里关闭，改为纯手动。

### 阅读位置记忆

每个文件的滚动位置都会被记住，下次打开自动回到上次读到的位置。

## 5. 新建文档

- 点击工具栏「**新建**」按钮（或命令面板 → 新建文档）。
- 弹窗中**只需输入文档名称**（默认 `未命名.md`，可带 `.md` / `.markdown` / `.txt` 扩展名），**没有保存地址选择**。
- 新文档立即进入**编辑模式**，编辑区呈现一张 **A4 纸面**（210×297mm，白色纸张、居中阴影）：
  - 正文区至少撑满一整页；
  - 内容超过一页后**向下无限延伸**（连续纸），纸面宽度恒定 A4 宽。
- 此时文档处于**内存中尚未写盘**，状态栏显示「未保存（新文档）」。
- **关闭该文档（退出编辑）时**弹出三选对话框：
  - **取消**——留在当前文档，继续编辑；
  - **不保存**——放弃更改，直接关闭（不写盘）；
  - **保存**——写盘。对话框中文件名下方有「**保存地址**」一行：
    - 显示**完整的文件夹路径**，默认为 Windows「文档」目录的真实路径（如 `C:\Users\你\Documents`）；
    - 路径为**可编辑输入框**，可直接手动修改；
    - 或点击右侧 📁 按钮**浏览选择任意文件夹**；
    - 目标文件夹不存在时自动创建。
- 保存后 A4 纸面自动恢复为常规版心；打开已有文件也使用常规版心。

## 6. 书架管理

书架是完全自定义的文档分类库（v1.0.5 起不再内置示例分类），与「最近打开」互补。

### 新建分类文件夹

1. 切到侧栏「书架」页签。
2. 点击顶部 **+** 按钮。
3. 在对话框中输入文件夹名称，确定。

### 重命名 / 删除文件夹

文件夹行右侧有两个按钮：

- ✏️ **重命名**：点击后输入新名称。
- 🗑️ **删除**：点击后确认。**删除只把文件夹移出书架，不删除任何源文件。**

### 添加 / 移除文件

- **添加**：点击文件夹行的 **+** 按钮，从文件对话框选择要加入的文档；或在打开某文档后，点书架顶部的「加入书架」按钮快速加入。
- **一键导入文件夹**：欢迎页「打开文件夹」按钮，选择一个目录后自动新建同名分类并把目录下所有 `.md` / `.markdown` / `.txt` 导入。
- **移除**：鼠标悬停文件夹内的文件条目，右侧出现 🗑️ 按钮，点击即从书架移出（源文件保留）。

书架数据自动保存，**下次启动自动恢复**。

## 7. 最近打开记录

- 自动记录最近打开的文件，最多 12 条。
- **单条移除**：鼠标悬停欢迎页任意记录，右侧出现 ✕ 按钮，点击移除该条。
- **全部清除**：「最近打开」标签右侧的「全部清除」按钮，一键清空。

## 8. 关闭软件与托盘常驻

点击右上角 ✕ 关闭软件时，会弹出「关闭 LightInk」对话框：

| 选项 | 行为 |
|---|---|
| **最小化到托盘** | 窗口收起，LightInk 常驻系统托盘继续后台运行。 |
| **退出** | 彻底退出程序。 |
| **取消** | 留在当前窗口，什么都不做。 |

- 对话框里有「**记住我的选择，下次不再询问**」勾选框：勾选后，下次点击 ✕ 直接执行所选行为，不再弹窗。
- **托盘操作**：双击托盘图标唤回主窗口；右键托盘图标可「显示主窗口」或「退出 LightInk」。
- 即使窗口被关闭/隐藏，软件仍在托盘后台运行——此时双击任何关联文件都会自动唤回界面并打开文件。

> 想恢复「每次关闭都询问」？关闭应用后删除 `%APPDATA%\LightInk\settings.json` 中的 `closeAction` 字段（或整个文件），重新打开即可。

## 9. 语法支持

完整覆盖 GitHub 风味 Markdown（GFM），并支持公式与图表。

| 元素 | 写法 |
|---|---|
| 标题 / 引用 / 列表 | `# 标题`、`> 引用`、`- 列表`、`1. 列表` |
| 任务列表 | `- [x] 已完成` / `- [ ] 待办`，编辑模式可直接点击勾选框切换 |
| 表格 | 管道语法 `| A | B |`，支持对齐标记 |
| 代码块 | 三个反引号包裹，指定语言获得语法高亮 |
| 脚注 | `文字[^1]`，文末 `[^1]: 说明` |
| 删除线 | `~~删除~~` |
| 链接 / 图片 | 标准语法；相对路径图片按文档所在目录解析 |
| 数学公式 | 行内 `$E=mc^2$`；独立行 `$$…$$`（KaTeX 渲染） |
| Mermaid 图表 | 代码块语言写 `mermaid`，支持流程图 / 时序图 / 甘特图等 |

`.txt` 文件也按 Markdown 渲染打开。

## 10. 查找

1. 按 `Ctrl F`（或命令面板 → 查找），右上角出现查找条。
2. 输入关键词，全部命中即时高亮，并显示「当前 / 总数」。
3. `Enter` 跳下一个，`Shift+Enter` 跳上一个。
4. `Esc` 关闭并清除全部高亮。

## 11. 导出

打开文档后，工具栏出现「导出」按钮（下拉菜单），两种格式：

| 格式 | 说明 |
|---|---|
| **HTML** | 单文件、完全自包含：样式、KaTeX 公式字体、文档内相对路径图片全部内联。发给任何人，浏览器双击即开。 |
| **PDF** | A4 版式，保留背景与配色。生成约需数秒，内部有 60 秒超时保护。 |

源码模式下请先切回「编辑」或「阅读」再导出。

## 12. 设置

工具栏「⚙ 设置」打开右侧抽屉，所有调整实时生效、自动记忆。

| 设置项 | 范围 |
|---|---|
| 正文字号 | 14 – 22 px（默认 17） |
| 行距 | 1.50 – 2.40（默认 1.90） |
| 版心宽度 | 36 – 56 em（默认 44；仅对打开的已有文档生效，新建文档为固定 A4 纸面） |
| 主题 | 跟随系统 / 浅色 / 深色 |
| 自动保存 | 开（默认）/ 关 |

## 13. 快捷键总表

| 按键 | 功能 |
|---|---|
| `Ctrl S` | 立即保存 |
| `Ctrl F` | 文内查找 |
| `Ctrl K` | 命令面板（搜索并执行所有命令） |
| `Enter` / `Shift+Enter` | 查找：下一个 / 上一个 |
| `Esc` | 关闭查找条 / 命令面板 / 设置抽屉 / 对话框 |
| `Ctrl Z` / `Ctrl Y` | 撤销 / 重做 |

## 14. 数据存在哪里

文档内容只保存在你的原文件里；应用自身数据都在本机：

```
%APPDATA%\LightInk\
├── recent.json     最近打开的文件列表
├── shelf.json      书架分类与关联文件
└── settings.json   排版设置、阅读位置、主题、关闭行为(closeAction)等
```

卸载应用不会删除你的文档；删除上述文件夹即可完全重置应用状态。

## 15. 常见问题

**双击 .md 文件没有用 LightInk 打开？**
右键文件 →「打开方式」→「选择其他应用」→ 选 LightInk 轻墨 → 勾选「始终使用此应用」。重装一次安装包也会重新注册关联。（若曾被 Notion 等其他软件接管过关联，需手动改回一次。）

**双击文件后没有进入阅读模式？**
先确认安装的是 v1.0.3 及以上版本。旧版在软件未运行时双击文件可能停在欢迎页；新版已修复，冷启动 / 已运行 / 托盘隐藏三种状态都会直接进入阅读模式。

**新建文档弹窗里出现了「保存地址」？**
v1.0.14 已修复。此前版本中该行会错误地显示在新建弹窗里；保存地址只应在**关闭未保存文档**时出现。

**新建文档时为什么是 A4 纸面？**
v1.0.8 起，新建文档的编辑区即一张 A4 纸，所见即打印所得；内容超过一页自动向下延伸。打开已有文件不受影响，使用常规版心（宽度可在设置中调整）。

**关闭时不想每次都弹「关闭 LightInk」对话框？**
勾选对话框里的「记住我的选择」即可。之后想恢复询问：关闭应用，删除 `%APPDATA%\LightInk\settings.json` 里的 `closeAction` 字段（或整个文件）。

**新建文档关闭时的三选对话框，选「不保存」会丢内容吗？**
会。选「不保存」表示放弃该文档的全部更改且不写盘；想保留请选「保存」，并可在保存前修改文件名与保存地址（手动输入路径或点 📁 选择，目录不存在会自动创建）。

**导出 PDF 很慢或没反应？**
正常生成需要数秒；内部有 60 秒超时保护，超时会提示。若文档包含大量 Mermaid 图，建议先切到阅读模式再导出。

**图片不显示？**
相对路径图片按「文档所在目录」解析，请确认图片与文档的相对位置未变。导出 HTML 时图片会自动内联，不受目录影响。

**公式 / 图表不渲染？**
公式必须成对：`$…$` 行内、`$$…$$` 独立行。Mermaid 必须写在语言为 `mermaid` 的代码块里。

**删除书架文件夹会删掉我的文件吗？**
不会。删除文件夹只是把它移出书架，里面的文档原封不动保存在原位置。

**想恢复初始设置？**
关闭应用，删除 `%APPDATA%\LightInk\` 下的 `settings.json`，重新打开即可（文档不受影响）。
