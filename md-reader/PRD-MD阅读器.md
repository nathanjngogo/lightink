## 1. 项目概述

### 1.1 定位

**本地 Markdown 编辑器 + 阅读器（Typora 形态）**：打开快、渲染保真、中文排版舒适、干扰少。本地散落的笔记 / AI 对话导出 / 技术文档是主要文档来源。

### 1.2 产品目标

* Typora 同款体验：所见即所得编辑，源码模式可切换，另有纯阅读态
* 中文阅读排版优先：合适字号、宽松行距、限宽版心
* 双击 `.md` 文件即开；自动保存，无"保存焦虑"

### 1.3 非目标

* ❌ 云同步 / 多端协作
* ❌ 双链、标签类笔记库管理（仅提供书架目录浏览）
* ❌ 应用内自动更新（手动覆盖安装）

## 5. 技术选型（已定）

本机实测（2026-09-01）：Node v22.23.2 ✅ / npm 10.9.8 ✅ / Rust ❌未装 / Python 3.11 ✅

| 层    | 选型                        | 理由                                 |
| ---- | ------------------------- | ---------------------------------- |
| 桌面壳  | **Electron**              | Node 已就绪零前置；编辑器生态最成熟；exe 打包链路最顺    |
| 编辑内核 | **Milkdown（ProseMirror）** | Markdown 原生所见即所得；插件覆盖公式/Mermaid/高亮 |
| 源码模式 | CodeMirror 6              | 成熟轻量，后期接入                          |
| 打包   | electron-builder（NSIS）    | 事实标准                               |

> 备选：Tauri（体积 \~10MB，但需先安装 Rust + MSVC 工具链）；若后续在意体积可迁移，前端层复用。
