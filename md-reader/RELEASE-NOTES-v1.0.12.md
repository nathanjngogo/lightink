# LightInk 轻墨 v1.0.12

界面布局优化。

## 优化

- **命令面板入口居中加宽**：工具栏的搜索入口移至**水平中部**（阅读 / 编辑 / 源码与右侧功能按钮之间），改为胶囊样式并加宽，文案为「搜索命令… Ctrl K」
- **命令面板弹层加宽**：弹出面板宽度 520px → 640px，命令列表更从容
- **「关闭文档」按钮移至工具栏**：从标题栏移到右侧功能组（主题按钮左侧），悬停显示红色提示；文件名与保存状态圆点仍保留在标题栏居中
