# LightInk 轻墨 v1.0.13

修复更新。

## 修复

- **新建文档弹窗不再显示「保存地址」行**
  - 根因：关闭/退出时的三按钮弹窗会临时改写对话框结构（三按钮 + 保存地址行）；若该弹窗被中断（异常退出等），残留状态会「泄漏」到下一次新建文档弹窗——这就是截图中新建时出现保存地址的原因
  - 修复：所有文本输入 / 确认类弹窗打开前强制复位到标准形态（两按钮、无地址行），彻底消除跨弹窗状态泄漏
- **退出时的保存路径行为保持 v1.0.11 语义不变**：关闭未保存文档时弹出完整路径（默认 Windows 文档文件夹），可手动编辑或点 📁 浏览选择
