# LightInk 轻墨 v1.0.11

保存流程体验优化。

## 变更

- **新建文档弹窗简化**：只保留文件命名输入，不再显示保存地址相关内容
- **关闭未保存文档弹窗**：「保存地址」一行改为显示**完整文件夹路径**
  - 新文档默认显示真实「文档」目录（如 `C:\Users\你\Documents`）
  - 已有文件显示其所在目录
  - 可直接看到保存到哪；可点击右侧 📁 按钮浏览更换文件夹
  - 路径过长时悬停可看完整路径
