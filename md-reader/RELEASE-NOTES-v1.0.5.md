# LightInk 轻墨 v1.0.5

书架清理与文档保存体验更新。

## 变更

- **移除旧示例书架**：「笔记 / 项目 / 示例」三个内置分类及其示例文档已移除，书架完全由用户自建分类组成（新建 / 重命名 / 删除均可用）
- **关闭未保存文档对话框重做**：三个选项
  - **取消**——留在当前文档继续编辑
  - **不保存**——放弃更改直接关闭
  - **保存**——可修改文件名，并在对话框中**直接选择保存地址**（默认「文档」目录，或原文件所在目录），也可点击按钮浏览选择其它目录
- 对话框打开时文件名自动选中（不含扩展名），直接输入新名即可
