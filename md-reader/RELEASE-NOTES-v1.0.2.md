# LightInk 轻墨 v1.0.2

书架管理与文档创建能力更新。

## 新增

- **书架 2.0 · 可管理**
  - 新建 / 重命名 / 删除分类文件夹（删除仅移出书架，不删除源文件）
  - 每个分类文件夹可添加 / 移除关联文档，条目悬停即现移除按钮
  - 顶部一键「把当前文档加入书架」；文档打开时标题栏旁也有快捷入口
- **新建 Markdown 文档**：工具栏「新建」按钮，应用内直接创建并进入编辑；关闭未保存的新文档时弹窗引导命名与保存位置
- **txt 全支持**：`.md` / `.markdown` / `.txt` 均可关联打开，书架与打开对话框同步支持

## 下载

| 文件 | 说明 |
|---|---|
| `LightInk-Setup-1.0.2.exe` | Windows 安装包（推荐）——自动注册 `.md` / `.markdown` / `.txt` 文件关联 |
| `LightInk-1.0.2-portable.zip` | 免安装便携版——解压即用 |

系统要求：Windows 10 / 11（64 位）。

> 安装包未做数字签名，SmartScreen 提示时选「更多信息 → 仍要运行」。
